## 1. Этапы выполнения ADAGIO™

SYNAPSE выстраивает рабочий процесс через три строгие последовательные фазы:

```
┌────────────────────────────────┐
│   Фаза 0: Оптимизация AutoML   │  ◄── Байесовский подбор гиперпараметров (Optuna)
└───────────────┬────────────────┘
                │ Сходимость оптимальных параметров
┌───────────────▼────────────────┐
│   Фаза 1: Золотой бутстрап     │  ◄── Загрузка архивов и калибровка базовой линии
└───────────────┬────────────────┘
                │ Защита целостности Ghost-File
┌───────────────▼────────────────┐
│   Фаза 2: Онлайн-конкурентность│  ◄── Неблокирующий цикл в 4 выделенных потока
└────────────────────────────────┘
```

### Фаза 0: Оптимизация AutoML
- Выполняет подбор гиперпараметров сетей MARKVART™ с помощью **Optuna**: скорость обучения, число мод Фурье ($k_{\max} \in [8, 32]$) и число голов внимания GATv2.
- Использует алгоритмы прунинга (`MedianPruner`) для остановки бесперспективных конфигураций.

### Фаза 1: Бутстрап «Золотого датасета»
- Агрегирует исторические дорожные логи, топологию OpenStreetMap и архивные показания датчиков.
- Формирует нормализованные непротиворечивые тензоры (**Golden Dataset**).
- **Защита Ghost-File**: Атомарная запись во временные файлы с проверкой контрольной суммы SHA-256 перед фиксацией в рабочем каталоге.

### Фаза 2: Онлайн-среда с 4 параллельными потоками
Среда реального времени распределяет нагрузку по четырем неблокирующим потокам:

1. **Поток сбора данных**: Прием сообщений по HTTP/MQTT/WebSocket и проверка байесовского доверия.
2. **Кинематический поток (KSE)**: Экстраполяция координат и скоростей с помощью фильтра Калмана при пропусках данных.
3. **Поток нейросетевого инференса**: Исполнение моделей MARKVART™ на GPU через CUDA Streams (PINO, GATv2, iTransformer).
4. **Поток HFT-вещания**: Сериализация матриц плотности в Protobuf и передача по gRPC в CARINA.

## 2. Кинематическое счисление (KSE) Dead Reckoning

При сетевых задержках или обрывах связи с датчиками модуль **KSE Dead Reckoning** сохраняет непрерывность данных:

### Вектор состояния фильтра Калмана
$$\mathbf{x}_k = \begin{bmatrix} s_k \\ v_k \\ a_k \end{bmatrix}$$

Где $s_k$ — координата смещения, $v_k$ — скорость, $a_k$ — ускорение.

### Модель перехода состояний:
$$\mathbf{x}_{k+1} = \mathbf{F} \mathbf{x}_k + \mathbf{w}_k$$

$$\mathbf{F} = \begin{bmatrix} 1 & \Delta t & \frac{1}{2}\Delta t^2 \\ 0 & 1 & \Delta t \\ 0 & 0 & 1 \end{bmatrix}, \quad \mathbf{w}_k \sim \mathcal{N}(0, \mathbf{Q})$$

Если данные не поступают более $N_{\text{missed}} \ge 3$ тактов, экстраполированное значение замещает датчик с переводом статуса в `FALLBACK`.
