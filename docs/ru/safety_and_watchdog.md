## 1. Независимый супервизор процессов F.E.N.I.X.

Для непрерывной работы на объектах критической городской инфраструктуры вычислительное ядро запускается под супервизором (`src/fenix/process_supervisor.py`):

```bash
python synapse.py --supervisor
```

### Основные задачи супервизора:
1. **Сигналы жизнеспособности (Heartbeats)**: Ядро отправляет импульсы каждые 250 мс. Отсутствие пульса более **500 мс** фиксируется как зависание.
2. **Лимит потребления памяти**: При превышении заданного порога RSS (например, 4096 МБ) супервизор инициирует принудительную сборку мусора или мягкий перезапуск рабочего процесса.
3. **Автоматическое восстановление**: При аппаратных сбоях CUDA или необработанных исключениях F.E.N.I.X. перезапускает воркер за время **менее 1.0 с**, восстанавливая подтвержденное состояние из чекпоинта.

## 2. Многоуровневая политика деградации (Gating Policy)

При сбоях в каналах связи модуль **Gating Policy** (`src/domain/gating_policy.py`) исключает попадание неопределенных значений (NaN/Null) в нейросеть:

```
┌────────────────────────────────────────────────────────┐
│               КАСКАД GATING POLICY                     │
│                                                        │
│  [Уровень 1: Полное нейросетевое восприятие]           │
│  Инференс MARKVART™ по подтвержденным датчикам         │
│                           │                            │
│                           ▼ (Кратковременный пропуск)  │
│  [Уровень 2: Кинематическое счисление (KSE)]           │
│  Экстраполяция фильтром Калмана (v, a)                 │
│                           │                            │
│                           ▼ (> 30 сек без связи)       │
│  [Уровень 3: Историческая микрооценка (MEH)]           │
│  Базовые профили распределения по часам суток          │
└────────────────────────────────────────────────────────┘
```

- **Уровень 1 (Нейросеть)**: Штатный режим при коэффициенте доверия $\tau \ge 0.70$.
- **Уровень 2 (KSE)**: Включается при единичных пропусках пакетов ($1 \le N_{\text{missed}} \le 30$).
- **Уровень 3 (История)**: Подключается при длительных отказах физического оборудования на линии.

## 3. Физические инварианты

Все поступающие пакеты проходят детерминированную проверку физических ограничений:
- **`SR-01 (Предел скорости)`**: $v \le 180\text{ км/ч}$ на городских улицах.
- **`SR-02 (Инвариант ускорения)`**: $|a| \le 8.5\text{ м/с}^2$ (предел торможения транспортного средства).
- **`SR-03 (Предел плотности)`**: $\rho \le \rho_{\text{jam}} = 140\text{ авт/км/полоса}$.
- **`SR-04 (Сохранение потока)`**: Баланс притока и оттока на узлах сети.
