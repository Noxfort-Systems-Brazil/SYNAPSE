## 1. Сущности пространственной топологии

Уличная дорожная сеть моделируется в виде ориентированного мультиграфа $G = (V, E)$, реализованного через строго типизированные dataclass-классы Python:

### `MapNode`
Представляет перекресток, точку ветвления дороги или виртуальный сенсор:
- `node_id: str`: Уникальный идентификатор (UUID или OSM ID).
- `latitude: float`, `longitude: float`: Географические координаты WGS84.
- `elevation: float`: Высота над уровнем моря в метрах.
- `node_type: NodeType`: Тип (`INTERSECTION`, `RAMP`, `MIDBLOCK`, `BRIDGE`, `TUNNEL`).
- `connected_edges: List[str]`: Ссылки на входящие и исходящие ребра.

### `MapEdge`
Представляет однонаправленный сегмент дороги между двумя узлами:
- `edge_id: str`: Уникальный идентификатор сегмента.
- `source_node_id: str`, `target_node_id: str`: Граничные узлы дороги.
- `length_meters: float`: Физическая длина участка в метрах.
- `lanes: int`: Количество активных полос движения ($N_l \ge 1$).
- `speed_limit_kmh: float`: Максимальная разрешенная скорость.
- `capacity_veh_per_hour: float`: Максимальная пропускная способность по модели Гриншилдса:
  $$C = v_f \cdot \frac{\rho_{\text{jam}}}{4}$$

## 2. Сущности сбора данных и источников

### `DataSource`
Моделирует физический или виртуальный источник телеметрии:
- `source_id: str`: Идентификатор поставщика данных.
- `name: str`: Описательное наименование датчика.
- `source_type: SourceType`: (`CAMERA`, `RADAR`, `INDUCTION_LOOP`, `BLUETOOTH`, `WAZE_API`, `TOMTOM_API`, `SUMO_SIM`).
- `protocol: IngestionProtocol`: Сетевой протокол (`HTTP_POST`, `MQTT_TOPIC`, `WEBSOCKET`, `GRPC`).
- `trust_score: float`: Динамический байесовский вес надежности ($0.0 \le \tau \le 1.0$).
- `status: SourceStatus`: Текущее состояние в валидаторе Zero-Trust.

## 3. Иерархия байесовского доверия

Для предотвращения искажения нейросетевых тензоров из-за недостоверных данных, SYNAPSE задает априорные веса доверия:

$$\tau_{\text{initial}} = \begin{cases} 0.95 & \text{Локальные наземные датчики (Петли, Радары, Камеры)} \\ 0.60 & \text{Внешние API (Краудсорсинг Waze, TomTom, Сотовые операторы)} \end{cases}$$

### Динамическое обновление доверия
Уровень доверия пересчитывается рекурсивно на основе физической непротиворечивости данных:

$$\tau_{t+1} = \frac{\tau_t \cdot P(E \mid \text{Valid})}{\tau_t \cdot P(E \mid \text{Valid}) + (1 - \tau_t) \cdot P(E \mid \text{Fault})}$$

Если $\tau_t$ опускается ниже $\tau_{\text{порог}} = 0.40$, источник автоматически переводится в пониженный статус.

## 4. Конечный автомат `SourceStatus` (Zero-Trust)

```
              ┌───────────────┐
              │   КАРАНТИН    │ ◄── Первичный прием данных
              └───────┬───────┘
                      │ Соответствие схеме данных
              ┌───────▼───────┐
              │  ВАЛИДАЦИЯ    │ ◄── Проверка физических лимитов ($|\Delta v| \le a_{\max}$)
              └───────┬───────┘
                      │ Серия корректных пакетов ($N \ge 10$)
              ┌───────▼───────┐
       ┌────► │   АКТИВЕН     │ ◄── Прямая передача в тензоры MARKVART
       │      └───────┬───────┘
Восстановление│ Потеря пакетов (> 3 пропущенных циклов)
       │      ┌───────▼───────┐
       └───── │   FALLBACK    │ ◄── Кинематическая экстраполяция KSE
              └───────┬───────┘
                      │ Длительный сбой или искажение
              ┌───────▼───────┐
              │   ОТКЛОНЕН    │
              └───────────────┘
```
