## 1. Структура тестовых наборов

Все тестовые сценарии расположены в каталоге `tests/` и сгруппированы по слоям:

- **Модульные тесты (`tests/unit/`)**: Изолированная валидация доменных сущностей, математических функций и конечных автоматов.
- **Тесты нейросетей (`tests/models/`)**: Проверка прямого и обратного проходов (forward/backward), размерностей тензоров и градиентов для 11 моделей MARKVART™.
- **Интеграционные тесты (`tests/integration/`)**: Сквозная проверка потока данных от сетевых адаптеров до выхода gRPC-стримера.
- **Тесты IPC (`tests/ipc/`)**: Нагрузочное тестирование протокола JSON-RPC через стандартные потоки при пиковых нагрузках.
- **Бенчмарки (`tests/benchmarks/`)**: Замеры времени цикла инференса, профилирование памяти и пропускной способности.

## 2. Запуск тестов

Перед запуском активируйте виртуальное окружение:

```bash
source .venv/bin/activate
```

### Запуск полного набора Pytest:
```bash
pytest tests/ -v
```

### Запуск с формированием отчета о покрытии:
```bash
pytest --cov=src --cov-report=term-missing --cov-report=html tests/
```

### Запуск тестов исключительно нейросетевых моделей:
```bash
pytest tests/test_neural_models.py -v
```

## 3. Синтетический трафик и детерминированные моки

Для проведения тестов в изолированных контурах без подключения к реальным радарам:

- **`SyntheticTrafficGenerator`**: Генерирует реалистичный трафик на базе уравнений Гриншилдса и ударных волн.
- **`MockHftReceiver`**: Виртуальный сервер gRPC в оперативной памяти для проверки схемы и сетевых задержек.
- **Фиксированные генераторы случайных чисел**: Все тесты фиксируют сиды (`torch.manual_seed(42)`) для обеспечения побитовой воспроизводимости.
